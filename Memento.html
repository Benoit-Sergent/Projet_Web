🚀 Memento Git : Projet SmartCampus

Utilisez ce guide pour maintenir une progression GitHub rigoureuse, un critère clé pour votre évaluation.

Workflow Quotidien

ActionCommande
Mise à jour (avant travail)git pull origin main
Préparation des fichiersgit add .
Sauvegarde localegit commit -m "feat: description claire"
Envoi sur GitHubgit push origin main

Gestion Avancée

Conseil : Pour éviter les conflits, travaillez sur des branches dédiées : git checkout -b feature/nom-fonctionnalité.

Structure du .gitignore

Ne poussez jamais les dossiers de dépendances ou fichiers de configuration locaux !
